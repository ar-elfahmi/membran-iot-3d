# Proyek: Smart Mixed-Matrix Membrane Gas Separation System (IoT) - 3D Interaktif

## Tujuan
Model 3D interaktif di web untuk pameran produk. Mudah dikustomisasi.

## Aturan teknis
- Three.js via CDN (importmap), ES modules, TANPA build tool.
- Struktur: index.html, src/main.js, src/config.js, src/components/*.js, src/ui/*.js, src/data/*.js
- Satu file per komponen 3D. Setiap komponen mengekspor fungsi create...() yang
  mengembalikan THREE.Group dengan userData {id, name, desc, pins}.
- Semua warna, posisi, ukuran, label, dan ambang batas ada di src/config.js.
- Gunakan bentuk primitif (silinder, kotak, torus). Jangan mengunduh model eksternal.
- Warna kabel mengikuti legenda diagram: merah=daya, jingga=warna/kontrol,
  hijau=komunikasi, biru=data, hitam=GND.
- Bahasa label UI: Indonesia dengan istilah teknis Inggris seperti di diagram.

## Cara kerja
- Kerjakan HANYA slice yang diminta. Jangan menyentuh file di luar cakupan slice.
- Jangan menulis ulang file yang tidak perlu diubah. Edit seperlunya.
- Setelah selesai, tulis ringkasan singkat: file yang diubah dan cara mengujinya.
- Referensi diagram sistem: docs/engineering-system-diagram.jpg (disebut docs/diagram-sistem.jpg pada brief).
- Referensi diagram logika: docs/gerbang-logika.jpg (disebut docs/diagram-logika.png pada brief).
- Referensi data: docs/Raw Data LLM.docx.

## Catatan diagram
Diagram dibuat AI dan ada label yang rusak (contoh: "MND", "Apom Failure", pin yang
tidak konsisten). Ikuti struktur dan alur secara umum, jangan menyalin pin dan teks
yang tidak masuk akal.

## Progres slice
- Slice 0 selesai: struktur ES modules, importmap Three.js 0.170.0, OrbitControls.
- Slice 1 selesai: scene dasar, grid, pencahayaan dan soft shadow, kamera responsif, 18 placeholder berlabel, overlay judul.
- Slice 2 selesai: housing membran transparan dengan bundel hollow fiber, end cap/flange dan tiga port, pipa berkurva dengan label/panah statis, flow meter inline, Pressure Sensor dan Temperature Sensor di atas housing. Kurva pipa tersedia di userData.curve untuk Slice 8.
- Slice 3 selesai: breakout SDP31 dengan P1/P2, header I2C dan selang tekanan berwarna ke tee inlet/retentate; Flow Sensor I2C inline pada kurva permeate CO2. Konfigurasi di sensing.
- Slice 4 selesai: ESP32 dengan statusLed, Wi-Fi/Bluetooth, MQTT Broker, Cloud, ponsel dan laptop. Dashboard dummy bertanda DEMO; screenCanvas dan screenTexture tersedia untuk Slice 9. Konfigurasi di controller dan communication. Actuation tetap placeholder; tanpa kabel listrik atau animasi baru.
- Slice 5 selesai: tiga Solenoid Valve inline (inlet setelah Flow Meter In, permeate setelah Flow Sensor, retentate sebelum Flow Meter Out), pompa vakum setelah Valve 2 dengan userData.rotor, dan H-BRIDGE DRIVER sejajar ESP32. setOpen(bool)/setRunning(bool) hanya memperbarui LED dan state. Mesh pipa terpotong tepat di port perangkat; userData.curve tetap kontinu untuk Slice 8. Ukuran, warna dan penempatan aktuator di actuation. Label ESP32/Flow Sensor diperbaiki, batas zona putus-putus otomatis dari bounding box badan perangkat dengan padding layout.zone, serta flange pada tiga ujung pipa terbuka. Tanpa kabel atau animasi baru. Verifikasi browser: 18 perangkat, nol overlap tak disengaja, tujuh sambungan inline rapat, empat LED dan rotor statis lolos.
- Tata letak: Actuation bergeser ke kanan, Communication direnggangkan. Di localhost/127.0.0.1/[::1], checkLayoutOverlap() berjalan otomatis dan dapat diulang dari console; memeriksa Box3 badan perangkat, mengecualikan jalur pipa/selang dan melaporkan kontak mekanis yang disengaja secara terpisah. Label CSS2D diperiksa secara visual.
- Verifikasi ulang Slice 5 (6 November 2026): Chrome headless tanpa error JavaScript; 18 perangkat, nol overlap tak disengaja, 14 ujung sambungan pada tujuh perangkat inline rapat, empat method LED/state dan penolakan input non-boolean lolos, rotor tetap statis, empat batas zona sesuai bounding box + padding, tiga flange terpasang. Tampilan desktop 1600×1000 diperiksa; implementasi src/ yang ada sudah memenuhi brief.
- Slice 6A selesai: adaptor 12V dan regulator 5V/3.3V di Controller; port listrik lokal Vector3 pada perangkat dan helper getPortWorld() di components/cables.js. Sebanyak 21 kabel fisik memakai lane, via, fillet dan lengkungan di atas pipa; empat tautan jaringan putus-putus hijau di udara. Lima grup layers diekspor untuk Slice 6B. Alias solenoidValve1–3 mempertahankan ID valve1–3 yang sudah ada. Label zona berjangkar kiri atas dengan offset config; label komponen dirapikan, SDP31 didekatkan ke depan membran, P1 setelah Valve 1 dan P2 sebelum Valve 3. Wi-Fi didekatkan ke ESP32 untuk kabel UART pendek. Verifikasi Chrome 1600×1000: checkLayoutOverlap() memeriksa 19 perangkat, nol overlap tak disengaja; checkCableClearance() memeriksa 25 koneksi, nol benturan. Endpoint, transform port, warna, lima layer, sembilan rute di atas pipa (clearance permukaan minimum 0.18 unit), label dan selang bebas tabrakan, rotor statis; tanpa error JavaScript. Pemeriksaan dev tersedia di localhost. Tanpa animasi baru, panel UI, toggle layer atau legenda.
- Slice 6B selesai: panel layer kanan atas dengan delapan checkbox, default semua aktif kecuali GND, preset “Hanya jalur gas” dan “Semua”, serta collapse. Toggle pipa mengatur 16 mesh pipa/flange/panah tanpa menyembunyikan perangkat inline; label komponen dan batas zona dikontrol terpisah. Legenda kiri bawah memuat sepuluh warna kabel, selang P1/P2 dan aliran gas langsung dari config. Tema gelap, fokus keyboard, Space dan Escape; pada layar kecil panel menjadi ikon dan legenda mulai diciutkan. Verifikasi Chrome pada 1600×1000, 1440×900, 768×1024, 390×844 dan 390×568: checkbox, preset, collapse, warna legenda dan keyboard lolos; tanpa overflow horizontal atau error JavaScript. Geometri, hierarki, transform dan rute tetap; 19 perangkat dan 25 koneksi diperiksa dengan nol benturan. Pemeriksaan visual: nol FAIL; peringatan ukuran label 3D lama pada ponsel tetap di luar cakupan slice.
- Slice 6C selesai: SDP31 dipindahkan ke belakang pipa, di antara membran dan ESP32, dengan header menghadap klaster kontrol; H-bridge didekatkan ke ESP32. Kabel memakai via manual 2D/3D, harness berjarak 0.085 unit, crossingClearance 0.20 unit dan kenaikan singkat dekat terminal inline. checkCableStats() tersedia hanya melalui console dev localhost, mencetak panjang seluruh 25 koneksi dan lima detour terbesar; rasio maksimum 1.899, tanpa pelanggaran ambang 2.0. Selang P1 #F0A030 dan P2 #38BDF8 beradius dua kali kabel, semi-transparan mengilap dengan garis putih, mengikuti layer Pipa gas. Label memakai prioritas config (zona > membran > ESP32/SDP31/valve/pompa > lainnya), pemeriksaan kotak layar tiap delapan frame serta opacity berdasarkan jarak/halangan. Offset label pompa dan perangkat dirapatkan; sembilan batas zona tanpa overlap mengikuti perangkat, Actuation terpisah per driver/valve/pompa. Legenda tertutup secara default di semua ukuran layar. Verifikasi Chrome 1600×1000, 1440×900, 768×1024, 390×844 dan 390×568: checkLayoutOverlap() memeriksa 19 perangkat tanpa overlap tak disengaja; checkCableClearance() memeriksa 25 koneksi tanpa benturan; endpoint tepat, crossing kabel 0.20 unit di atas permukaan pipa, kedua selang bebas komponen, toggle/preset dan pemisahan label/zona lolos, nol overlap label yang tampil, nol overflow horizontal atau error JavaScript. Empat sudut/jarak kamera diperiksa; pemeriksaan visual nol FAIL, peringatan teks label 11–12 px pada ponsel dipertahankan agar anotasi zona tetap kecil dan samar sesuai brief. Tanpa animasi atau interaksi baru.
- Penyesuaian Slice 6C: kabel ctrl-valve3 dari H-bridge OUT3 berjalan rendah melalui bawah pipa permeate hijau, lalu naik dekat koil Valve 3. Opsi underPipes di config mengecualikan hanya pipa tersebut dari lengkungan otomatis. Verifikasi Chrome 1600×1000: 19 perangkat tanpa overlap, 25 koneksi tanpa benturan, detour kabel Valve 3 sebesar 1.361 dan clearance permukaan terhadap bagian bawah pipa hijau minimum 2.955 unit; tanpa error JavaScript.
- Slice 7 selesai: raycaster hanya pada mesh perangkat, hover ringan dengan throttle 60 ms, highlight pilihan tanpa mengubah LED status, serta label hover/pilihan yang mengatasi prioritas dan toggle label. Klik/tap membuka panel info dan fokus kamera dengan tween 0,6 detik; drag/pinch tidak dianggap klik, area kosong dan Esc membatalkan pilihan. Panel kanan berubah menjadi bottom sheet pada tablet/ponsel, memuat zona, desc, koneksi otomatis berwarna dari config.cables (termasuk alias valve), tabel userData.ports, spesifikasi config.info, navigasi koneksi, dan tombol visual valve/pompa. Pemilih komponen native tersedia di panel layer untuk akses keyboard. Semua 19 entri info memiliki desc yang dapat diedit dan specs kosong. Empat preset kamera dan Reset memakai tween bersama; reduced motion langsung mencapai target. Slider Explode memakai lerp dan offset config: perangkat terangkat, housing transparan naik sementara hollow fiber tetap; ring geometri pipa dan kedua selang tekanan mengikuti endpoint perangkat. Keputusan fallback: hanya kabel disembunyikan selama explode > 0, lalu dipulihkan pada 0 tanpa mengubah pilihan layer; pipa/selang tetap mengikuti toggle Pipa gas. Rakit kembali memulihkan posisi persis. Label zona berada di luar sudut kiri atas kotak dalam proyeksi layar, menghindari badan komponen dan label zona lain, dengan kontras lebih jelas. Legenda selalu mulai tertutup setelah reload dan hanya mengikuti toggle eksplisit selama sesi halaman. Verifikasi Chrome 1600×1000, 1440×900, 768×1024, 390×844, dan 390×568: hover/klik/tap, penolakan drag, panel, koneksi/pin, empat tombol aktuator, preset, label paksa, explode/rakit kembali, pemulihan layer dan legenda lolos; checkLayoutOverlap() pada explode = 0 memeriksa 19 perangkat tanpa overlap tak disengaja, checkCableClearance() memeriksa 25 koneksi tanpa benturan. Endpoint pipa/selang rapat, rotor statis, tanpa overflow horizontal atau error JavaScript. Pemeriksaan visual otomatis: nol FAIL; label 3D ponsel 11–12 px tetap sebagai catatan keterbacaan. Tanpa animasi aliran gas, data live, simulator atau logika kontrol baru.
